# Thư mục nguồn (source)

Đặt file mô hình gốc VinFast VF 9 vào đây với tên `vf9-source.glb` (hoặc `.gltf`
kèm `.bin` và ảnh texture), rồi chạy `npm run model:prepare`.

Mô hình đề xuất: "Vinfast VF9 model (no interior)" của Giang Trần trên Sketchfab,
giấy phép CC Attribution 4.0. Xem README ở gốc dự án để biết cách tải.

Nội dung thư mục này (trừ file README) không được đưa vào git.
